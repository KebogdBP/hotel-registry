# Hotel Registry

Hotel Registry — учебный проект по настройке бесплатного CRM-портала для небольшой гостиницы. Система помогает администратору регистрировать обращения гостей, проводить бронирования по этапам, фиксировать отказы и видеть историю повторных гостей.

Проект реализуется стандартными средствами Bitrix24 без разработки отдельного сайта:

- контакт хранит имя и телефон гостя;
- сделка хранит конкретное обращение или бронирование;
- одна воронка показывает текущее состояние каждого обращения;
- повторные бронирования связываются с существующим контактом.

## Текущий статус

Портал настроен и проверен на бесплатном тарифе после завершения пробного периода. Поля, стадии, отказ и история повторного гостя работают. Текущий этап — запись и проверка приёмочного видео.

## Ближайший результат

Настроенный портал должен позволять:

1. Создать обращение со всеми данными гостя и бронирования.
2. Перемещать обращение по стадиям до заселения.
3. Закрыть обращение отдельным статусом отказа.
4. Создать повторную бронь для существующего гостя и показать предыдущую.
5. Подтвердить на видео, что решение работает на бесплатном тарифе без активного демо-режима.
